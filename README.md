# Process Scheduling Simulator (Java)

## Overview
This project demonstrates basic CPU scheduling using the First Come First Serve (FCFS) algorithm.

## Features
- Simulates execution of multiple processes
- Calculates waiting time for each process
- Calculates turnaround time for each process
- Displays scheduling results in a table format

## Technologies Used
- Java
- ArrayList

## How to Run
1. Open the project in IntelliJ IDEA
2. Run the `ProcessSchedulingSimulator.java` file
3. View results in the console

## Example Output
Process   Burst Time   Waiting Time   Turnaround Time  
P1        5            0              5  
P2        3            5              8  
P3        8            8              16  
P4        6            16             22
